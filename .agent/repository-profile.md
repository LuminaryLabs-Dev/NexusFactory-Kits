## Maintenance scope

This repository owns:

- factory domains and capabilities;
- public Kit manifests and generator implementations;
- deterministic randomization and hashing;
- mesh, textured-mesh, raster, generation-state, validation, and export contracts;
- registry construction;
- repository tests, demos, review tools, workflow, and documentation.

NexusFactory-Studio is the linked generic consumer. It owns registry loading, controls, viewers, snapshots, and downloads, not generator-specific behavior.
